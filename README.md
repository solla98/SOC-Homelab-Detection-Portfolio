# SOC-Homelab-Detection-Portfolio

Hands-on SOC detection scenarios built in a personal homelab using Splunk.

---

## Overview

This repository documents analyst-style detection use cases built through hands-on attack simulation, log analysis, and SIEM-based detection logic.

---

## Environment

- Attacker: Kali Linux
- Victim: Ubuntu Server
- SIEM: Splunk
- Log Sources: Linux authentication and system logs

---

## Detection Scenarios

1. SSH Brute Force Attack Detection
2. Successful SSH Login (Credential Compromise)
3. Privilege Escalation Attempts
4. Suspicious Command Execution
5. Port Scanning Activity
6. Web Attack Simulation

---

## Skills Demonstrated

- Log analysis and correlation
- Splunk SPL and regex field extraction
- Detection logic design
- SOC incident analysis workflow
